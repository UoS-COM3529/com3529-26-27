# COM3529 Practical Session 8: Code Defenders

## Instructions

This lab will consist of a live session playing [Code Defenders](../slides/8-mutation-testing.pdf).

To prepare for the lab, you are simply asked to create an account on https://code-defenders.org.

To warm up and get used to Code Defenders interface, we will spend the first 15 minutes of the lab completing as many _puzzles_ as we can on the game: https://code-defenders.org/puzzles.

In the main part of the lab session, you will follow instructions to join specific pre-created games and play against each other.

The goal of the session is to solidify your understanding of Mutation testing through playing Code Defenders. While playing the game, reflect on key concepts like the quality of mutants, the relationship between tests achieving coverage and killing mutants, the problem of equivalent mutants, etc.

Code Defenders is open-source and actively developed. If you are interested in contributing to the project, please check-out the GitHub repo at https://github.com/CodeDefenders/CodeDefenders.

Enjoy!

> There is no solution for this lab.
